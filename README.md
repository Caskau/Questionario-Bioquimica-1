# Simulado de Bioquímica com Flashcards

Este projeto contém um simulado de 100 questões com:

- Correção automática
- Avaliação por tema (Enzimas, Proteínas, etc.)
- Recomendações de estudo
- Flashcards por tema com base no desempenho

## Como usar

1. Faça login com seu nome (único).
2. Responda as 100 questões.
3. Veja seu resultado e revisão por tema.
4. Estude com os flashcards personalizados.

## Publicação

Para publicar no Vercel:

1. Faça fork deste repositório.
2. Vá até https://vercel.com/import
3. Selecione seu fork e clique em Deploy.

Framework: React (Vite ou CRA)
